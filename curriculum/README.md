# CS103/CS104 Java Programming Curriculum

This folder contains the complete instructional materials for the second-semester
portion of the Java programming course (Weeks 19–36), including full lecture and
laboratory modules for Weeks 23–36. The course uses **Eclipse IDE** for all Java
development, progresses from console applications into **Swing GUI programming**,
and finishes with a **Java Swing + SQLite** database application.

Course structure:

- **First Semester:** Weeks 1–18
- **Second Semester:** Weeks 19–36

Weeks 1–22 are summarized below as a curriculum outline only, since students are
assumed to have already completed that material (introductory Java, OOP, arrays,
files, and exception handling). Full instructional modules begin at **Week 23**,
where GUI programming is introduced, and continue through **Week 36**, the final
examination and project presentation week.

## Weeks 1–22 Curriculum Outline

| Semester | Week | Lesson Title |
|---|---:|---|

| First Semester | 3 | Variables, Data Types, Type Casting, Unicode, and Basic Input |
| First Semester | 4 | User Input, Date and Time, Expressions, and Introductory Problem Solving |
| First Semester | 5 | Java Operators: Arithmetic, Assignment, Relational, Logical, Unary, Bitwise, and Precedence |
| First Semester | 6 | Decision Making: if, if-else, nested conditions, and switch statements |
| First Semester | 7 | Loop Control: for, for-each, while, do-while, break, and continue |
| First Semester | 8 | Methods, Parameters, Return Values, Variable Scope, and Code Reuse |
| First Semester | 9 | Midterm Examination |
| First Semester | 10 | Arrays, Multidimensional Arrays, Final Arrays, Number, Boolean, Character, Wrapper, and Math Classes |
| First Semester | 11 | Object-Oriented Programming: Classes, Objects, Attributes, Methods, and Constructors |
| First Semester | 12 | Encapsulation, Access Modifiers, Packages, and Class Design |
| First Semester | 13 | Inheritance, Aggregation, Polymorphism, Method Overriding, and Method Overloading |
| First Semester | 14 | Dynamic Binding, Static Binding, Initializer Blocks, Abstraction, and Interfaces |
| First Semester | 15 | Inner Classes, Static Classes, Anonymous Classes, Singleton Classes, and Enums |
| First Semester | 16 | Java File Handling: Files, Directories, Creating, Reading, Writing, Deleting Files, and I/O Streams |
| First Semester | 17 | Java Exceptions: try-catch, finally, try-with-resources, multi-catch, throw, custom exceptions, and exception propagation |
| First Semester | 18 | Final Examination / Console Application Presentation |
| Second Semester | 19 | Java Review: OOP, Arrays, Files, and Exceptions for Application Development |
| Second Semester | 20 | File-Based Java Applications: Persistent Text Data and Structured Program Design |
| Second Semester | 21 | Advanced Exception Handling and Defensive Input Validation |
| Second Semester | 22 | Preparing for GUI Programming: Event-Driven Thinking and Java Application Planning |
